# EDFbrowser Tap

Homebrew tap for the Apple Silicon release of EDFbrowser.

> [!IMPORTANT]
> This build supports Apple Silicon Macs only.
> Intel-based Macs are not supported.

## Installation
```bash
brew tap sjg2203/tap https://github.com/sjg2203/EDFbrowser-Tap.git
brew install --cask sjg2203/tap/edfbrowser
```
